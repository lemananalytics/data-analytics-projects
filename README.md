# Data Analitika və Statistika Layihələrim

Bu repozitoriyada mənim data analitikası, statistika, maşın öyrənməsi öncəsi data validasiyası, SQL sorğuları və Power BI vizuallaşdırması üzrə işlədiyim real biznes layihələri toplanmışdır.

---

## Layihələr Kataloqu:

* **[Qovluq 1: Pərakəndə Satış Məlumatlarının Təmizlənməsi və Analizi](./01-Parakanda-Satis-Analizi/)**  
  * **Texnologiyalar:** Python (Pandas, NumPy)  
  * **Biznes Dəyəri:** Duplikat və boş dataların təmizlənməsi (ETL), yeni maliyyə metriklərinin yaradılması (Feature Engineering) və regionlar üzrə performans hesabatları.

* **[Qovluq 2: İşçi Maaşlarının OLS Reqressiya və Statistik Analizi](./02-Maas-Reqressiya-Analizi/)**  
  * **Texnologiyalar:** Python (Statsmodels, SciPy, Pandas)  
  * **Biznes Dəyəri:** Normallıq testləri (Shapiro-Wilk, Kolmogorov-Smirnov), hiptoz testləri (Mann-Whitney / T-test), OLS Reqressiya modeli ilə maaş proqnozlaşdırılması və multikollinearlıq probleminin aşkar edilməsi.

* **[Qovluq 3: NSL-KDD Kibertəhlükəsizlik Datalarının Analizi və Hücum Təsnifatı](./03-NSL-KDD-kibertəhlükəsizlik-analiz/)**  
  * **Texnologiyalar:** Python (Pandas, Scikit-learn, Matplotlib/Seaborn)  
  * **Biznes Dəyəri:** Şəbəkə trafikində anomaliyaların təhlili, kibertəhlükəsizlik hücum növlərinin təsnifatı və risk dərəcələrinin qiymətləndirilməsi.

* **[Qovluq 4: DVD Rental Relasiyalı Databaza SQL Analizi](./DVDRental-data-analizi/)**  
  * **Texnologiyalar:** SQL (PostgreSQL), Python / Excel  
  * **Biznes Dəyəri:** Çoxlu cədvəllərdən ibarət relasiyalı databazadan istifadəçilərin icarə vərdişləri, film janrlarının gəlirliliyi və müştəri loyallığı üzrə mürəkkəb JOIN/AGGREGATE sorğuları ilə biznes metriklərinin çıxarılması.

* **[Qovluq 5: Bakı Daşınmaz Əmlak Bazarının Təhlili və Power BI Dashboard](./Daşınmaz%20əmlak%20analizi/)**  
  * **Texnologiyalar:** Power BI (DAX, Power Query), Excel, Python  
  * **Biznes Dəyəri:** Bakı şəhəri üzrə mənzil elanlarının təmizlənməsi, $m^2$ qiymətləri, yerləşmə (rayon/metro) və investisiya gəlirliliyi (ROI/Rental Yield) üzrə interaktiv dashboard-un hazırlanması.
