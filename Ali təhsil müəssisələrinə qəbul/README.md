# 📊 Azərbaycan Ali Təhsil Müəssisələrinə Qəbul Analizi (2021)

Bu qovluq 2021-ci il üzrə Azərbaycan Respublikasının ali təhsil müəssisələrinə qəbul göstəricilərinin (I-IV ixtisas qrupları və V qrup) statistik təhlili, Power BI interaktiv dashboardı və yekun strateji hesabatını ehtiva edir.

---

## 📁 Qovluğun Məzmunu

* **`Universitetlər qəbul.pbix`** — Power BI interaktiv dashboard faylı (mülkiyyət tipi üzrə filtrasiya, keçid balları və plan yerlərinin asılılıq diaqramı).
* **`Hesabat.pdf`** — Statistik təhlillərin nəticələri, modelləşdirmə tapıntıları və strateji təklifləri əks etdirən rəsmi PDF hesabatı.
* **`Universitetlər qəbul.ipynb`** — Məlumatların təmizlənməsi, vizuallaşdırılması və hesabatın avtomatik generasiyası üçün istifadə olunan Python kodu.

---

## 📈 Təhlilin Əsas Tapıntıları

* **Plan Yerlərinin Bölünməsi:** Cəmi **50K** plan yerinin **81.44%-i** (40K+) dövlət, **18.56%-i** (9K) isə özəl universitetlərin payına düşür.
* **Akademik Göstəricilər:** I-IV qruplar üzrə ortalama keçid balı dövlət universitetlərində daha yüksəkdir (~365 bal), top liderlər isə BANM, ATU və ADA Universitetidir.
* **Səpələnmə Analizi (Scatter Plot):** İri tutumlu dövlət ali məktəbləri yüksək tələbə qəbulu ilə yanaşı ortalama keçid balını da yüksək səviyyədə saxlamağı bacarır.
